# CI benchmark configurations

one config per test for regression detection. all use 100ms / 30M (profile 1).

## TestGasBurner (`30m_80pct`)

```env
BENCH_BLOCK_TIME=100ms
BENCH_SLOT_DURATION=100ms
BENCH_GAS_LIMIT=0x1C9C380
BENCH_SCRAPE_INTERVAL=25ms
BENCH_NUM_SPAMMERS=4
BENCH_COUNT_PER_SPAMMER=6000
BENCH_THROUGHPUT=60
BENCH_WARMUP_TXS=200
BENCH_GAS_UNITS_TO_BURN=1000000
BENCH_MAX_WALLETS=200
BENCH_WAIT_TIMEOUT=10m
```

expected: 148 Mgas/s, 150 TPS
